## 7. Gotchas learned — worth not rediscovering

- **`npm run test` in a fresh worktree exits 0 while printing `vitest: command not found`.** A
  non-run that reads as a pass. Symlink the main checkout's `node_modules`, or review in the main
  checkout (the `id:15d5` pattern). Read the *output*, never the exit code.
- **`cmd | tail -N` in a backgrounded Bash call persists only N lines** — the failing-file list is
  gone when you need it. And **a pipe masks the exit code**: `check-gallery-gate.mjs | tail` gave
  `0` while the script exits `1`.
- **A green unit suite is not a green repo.** `check-gallery-gate.mjs`, `version:check` and
  `test:snapshot-isolation` are all real gates that `vitest run` never invokes. Enumerate tiers
  from `package.json` before claiming "no regressions" (review.md §3).
- **`relay-reconcile.sh --integrate` only accepts `relay/orphan/*`.** A STRANDED branch must be
  renamed into that namespace first. Its `git branch -d` also refuses while a verify worktree still
  holds the branch — it warns and leaves the ref, which is correct and non-destructive.
- **Reconcile checkpoints are labelled `reconcile (…)` and deliberately do NOT advance
  `last_strong_ckpt`.** So `review.md` §1's `git tag | tail -1` gives a review agent an **empty
  window** right after a reconcile. Pin the window to `last_strong_ckpt` from `relay.toml`. Use the
  **full** model id in `ckpt-tag.sh -l` (`reviewer (claude-opus-5)`) or the strong watermark
  silently stays stale (`id:1a34`).
- **A doc-only diff still deserves a review** — puzzle-pwa's was doc-only and the review found a
  lane drift that `orphan-scan --cross-ledger` structurally cannot see, because it compares
  *checkbox state* only and both views read `[ ]`.
