## 8. A method note for the successor

Three times this session a verification grep anchored on adjacency to the `<!-- id -->` marker
produced a **false negative** that was briefly believed (the `eee6` re-lane, four lean4btc appends,
and escapement `dbb6`). A plain grep for the written text settled each instantly. **When a check
disagrees with a simpler check, the check is the suspect.** Related: `md-merge`'s `regex_sub`
rewrites ONLY the line carrying the `<!-- id -->` marker — a substitution aimed at a continuation
line of a multi-line item exits 0, commits, and changes nothing. Grep for the new text afterwards.
