## Traps this session paid for — do not rediscover

1. **`md-merge.py --append` with a MULTI-LINE payload** silently moves the id marker off the
   checkbox line and breaks `run-tests.sh`'s `item_open()` (`id:e166`). Single-line appends are safe.
2. **Some markers sit MID-line** with prose after them (`id:a955`). Never assume terminal position.
3. **Bash cwd persists between calls.** A relative `--file TODO.md` after an earlier `cd` into a
   worktree wrote six items into the wrong tree. Use absolute paths or `git -C`.
4. **`orphan-scan --cross-ledger` compares CHECKBOX STATE ONLY.** Same id with different *lanes*
   in the two ledgers is invisible to it (`a955` was `[HARD]` vs `[INPUT — decision]`).
5. **The lane-vocab ratchet blocks re-adding an old venue-keyed tag** — touching such a line
   re-stages it as "added". Convert to capability-keyed vocabulary in the same edit.
6. **`awk -v` processes escape sequences** in variable values, so `^- \[ \]` silently degrades to a
   character class that also matches `- [x]`.
7. **`bash -n` is not sufficient** to validate a mechanical rewrite — it passed two mangled lines
   that only a token-level inverse check caught.
8. **Pipe-test a hook BEFORE registering it.** The guard denied in interactive sessions because
   `heartbeat.sh live-runs` always reports the non-pool `discovery-producer`. `deny` is *worse*
   than `ask` — it cannot be approved.
