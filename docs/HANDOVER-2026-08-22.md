## Traps this session paid for

1. **`test_destructive_git_guard_3a09.sh` asserts the guard is NOT wired** (`settings.json:909` — the
   owner has since wired it). The TEST is stale, not the code. It has been the sole suite failure all
   session. **Re-specify it; do not unwire anything.**
2. **`$?` after a pipe is the LAST command's status.** `cmd | head; echo $?` reports `head`. This
   produced a confidently wrong "exit 0" claim about `mech-currency.sh`, which exits 1 correctly.
3. **`git config --get-all credential.helper` misses the per-URL key** `credential.https://github.com.helper`.
   Produced a wrong "no credentials configured" diagnosis.
4. **`git diff m^1 m` overstates merge exposure** — the second parent's content IS scanned via its own
   commits. Use `git diff-tree --cc` for lines in neither parent.
5. **Agents stall waiting on their own background jobs.** Three ended turns saying "waiting for the
   suite" and never resumed. Brief them: *commit before running the suite; never end a turn waiting
   on your own background job.*
6. **The Agent tool's `isolation: worktree` is safe for same-repo work** but worktrees prevent
   clobbering, NOT merge conflicts. Partition by **file ownership** — one owner per file — and merges
   stay trivial. Held for 9 branches; the one conflict came from a branch that forked before a merge landed.
