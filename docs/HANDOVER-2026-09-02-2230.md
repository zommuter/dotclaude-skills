## 3. The owner's ledger LINE GRAMMAR (ratified this session)

A line in `TODO.md` / `ROADMAP.md` is valid iff it is exactly one of:

1. **BLANK**
2. **HEADING** `^#{1,6} `, <= ~200 chars, followed by a blank line, opening a non-empty
   section, never last in the file. **Nesting is legal down to level 4**; only a
   SIBLING-or-SHALLOWER following heading means an empty section.
3. **ITEM** `- [ ]/[x]` + optional lane tag + title <= ~200 + typed-edge comments + its own
   anchored id marker + END OF LINE.

**There are NO continuation lines.** Acceptance/Tests/Done-check prose lives in
`docs/ledger-notes/<id>.md`. Shipped in `todo-conformance.sh` as `id:b048`, **report-only**
(every `grammar-*` class counts in `findings`, never `strict_findings`).

form, not an `### Acceptance` heading. A note using headings reads as NO-ACCEPTANCE.

## 7. Traps paid for this session

- **A checker that derives its correctness from the thing it checks cannot fail.** `ff7c`
  sources `lib-typed-edges.sh` and `lib-lane-anchor.sh` and CALLS them rather than copying
  `ledger-shrink.py`'s regexes. It deliberately does NOT use `mask_backticks`, because
  `classify-repo.sh` does not either -- a backticked lane bracket IS the computed lane today
  (`id:1254`).
- **DECLARATIVE vs REFERENTIAL is the rule for editing an audit log.** Convert a tag that
  ASSERTS an item's lane. Never convert either side of a NARRATED transition between two
  old-vocabulary lanes -- rewriting an endpoint makes the log describe an event that did not
  occur. `[HARD - hands]` has no new-vocabulary form, so an arrow ending in hands is
  INEXPRESSIBLE in the new vocabulary and must stay wholly old.
- **Never blind `replace_all` across a file that describes its own edits.** It rewrote
  `401c.md`'s header declaration into self-contradiction. Split the file by region first.
- **`# roadmap:` and `# fails-against:` are mutually exclusive** in this repo's tooling:
  `verify-negative-cases.py` reports ROADMAP-SHADOWED and does not run the mutations.
  Unresolved.
- **A green suite is not evidence** when one agent wrote both code and test. Three
  independent checkers found six confirmed defects in work that was green and self-reported
  clean.
