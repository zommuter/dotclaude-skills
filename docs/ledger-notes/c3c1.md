## RETRACTION 2026-09-08 -- the 26,212 "system-prompt cost" above is INFLATED, do not quote it

(This note has been edited since authoring, per `docs/ledger-notes/README.md`.)

A review of the probe definitions found the split measurement is **not valid as
instrumented**. The claim in the section above -- *"wide-vs-narrow isolates tool-definition
cost; default-vs-wide isolates system-prompt cost"* -- is FALSE for the second half.

`preamble-probe-wide` declares 11 tools. A default delegated subagent actually receives
**21**: `Agent, Artifact, Bash, Edit, EnterWorktree, ExitWorktree, Monitor, NotebookEdit,
Read, SendMessage, Skill, TaskStop, WebFetch, WebSearch, Write` plus six `mcp__claude_ai_*`
tools. Thirteen are missing from the wide list, and they are not minor:

- **`Skill` carries the entire skills catalogue** -- the ~30-entry description listing that
  arrives as a system-reminder. Drop the tool, drop the catalogue.
- **`Artifact` and `Monitor` have the largest schemas** in the set.

So `default - wide` = system prompt **plus ~13 tool schemas plus the skills catalogue**, and
all of that surplus was booked as "system-prompt cost". The 26,212 figure is an upper bound
on the portable win, not a measurement of it, and the 4:1 prompt-vs-tools ratio derived from
it does not stand. **The direction of the error flatters the migration case**, which is the
dangerous direction: it makes the trim look more portable to a wide-toolset executor than the
evidence supports.

Second-order, same review: `preamble-probe-wide` declares `Agent` and the narrow probe does
not, so part of the measured "tool-definition cost" is the **agent-type registry** shipped
with that tool -- a component that grows every time a definition is added, including these
probes' own descriptions. Order ~700 tok today; wrong direction for an instrument.

**What still stands unaffected**: the `echo-runner` result (default haiku 54,844 vs custom
29,796 = 25,048, 45.7%) does not depend on any tool-list construction -- it compares a real
default dispatch against a real custom definition at matched model. The MECHANISM is proven.
What is retracted is only the decomposition into prompt-cost vs tool-cost.

**Corrective instrumentation, in flight**: `preamble-probe-wide` rebuilt to carry the literal
complete 21-tool default roster (so `default - wide` collapses toward the system-prompt swap
alone), plus a third probe `preamble-probe-exec` carrying the realistic executor list, which
is the delta that actually transfers to a `relay-implementer`. Re-measure all three before
quoting any split figure.
