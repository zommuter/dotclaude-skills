Every event emitted between two reassignments therefore carries an IDENTICAL timestamp regardless of when it happened. **How it misled, concretely:** lean4btc's integrate, puzzle-pwa's handback and loderite's handback all read `2026-08-22T14:04:10Z`, which looked like a simultaneous multi-unit event worth chasing as a slot/concurrency bug.
