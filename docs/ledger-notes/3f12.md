(owner 2026-07-24) — today a relay-managed repo has no sanctioned fast path: every route (`executor`/`review`/`hard`/`drain`) assumes the RED-spec-first discipline, so an urgent one-line bug fix either waits for a handoff to author a spec, or gets done off-contract and silently skips the ledger. Both are bad; the second is what actually happens. **WANTED:** a mode where the fix ships FIRST and the contract is satisfied AFTERWARDS, without that becoming a laundering channel. **The design tension to resolve in the meeting** — the executor contract's definition-of-done is "the item's *previously-failing* tests now pass" (contract rule 2), which a hotfix inverts: the test is written after the fix, so it can be written to fit whatever the fix happens to do. That is exactly the self-authored-spec hazard id:0c86/id:077d exist to catch (a spec its own author wrote proves only that the code does what the author decided). So a hotfix mode needs a *different* integrity story than "trust the executor", not a waiver of the existing one. **Questions the meeting must answer:** (1) what is the minimum tracked artefact at fix time — a minted id + a one-line RELAY_LOG entry, or a full ROADMAP item? (2) is the post-fact RED test *mandatory before the next integrate* (a debt the next `/relay review` refuses to pass over), or advisory? (3) how is the post-fact test kept honest — mutation-test it against the pre-fix commit (it MUST fail there), which is mechanically checkable and is the natural anti-gaming primitive here; (4) what stops scope creep — a declared one-item scope with any spill-over becoming a filed follow-up rather than a widened fix, and a diff-size or file-count tripwire that forces a handback; (5) does it route through REVIEW_ME (a box the next review must clear) or straight to ROADMAP as a `[ROUTINE]` debt item; (6) who may invoke it — human-only, or may the pool self-declare a hotfix? Prior art in-repo: id:b780's "a review child fixed a flaky test in-flight" was RULED OUT OF SCOPE 2026-07-19 precisely because a verifier that can fix the artefact it verifies can launder its verdict — a hotfix mode must not re-open that hole by the back door.
