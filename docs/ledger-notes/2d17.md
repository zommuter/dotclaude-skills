### The contradiction, stated plainly

**The RED spec `tests/test_shape_prose_regrowth_baseline_2d17.sh` cannot be satisfied by
the mechanism the owner ratified for this item.** Not "is hard to satisfy" -- cannot, and
the note above says so in its own words without drawing the conclusion:

> its case 5 regrowth is SMALLER than the baselined value, **which disarms both the
> id-keyed and the snapshot designs**

The ratified decision (recorded above, 2026-09-02) is *"MANDATORY REGEN plus a STALENESS
DETECTOR ... Self-tightening was the alternative and was NOT chosen"* -- i.e. **the snapshot
design**. The spec disarms the snapshot design by construction. Both are correct documents;
they were written against different mechanisms and the conflict was never noticed because
nothing had been built against them at the same time.

Demonstrated, not reasoned -- with the implementation below in place:

```
state 0  Bravo 76 chars   -> baseline captures bbb2 = 76
state 1  Bravo  0 chars   -> clean under --strict            (assertion 0 PASSES)
state 2  Bravo 29 chars   -> 29 <= 76 -> shape-grandfathered  WARN, rc=0
                             assertion (1) FAILS: "a REGROWN item did NOT fail --strict"
```

Only a baseline that TIGHTENED to the observed 0 at state 1 turns `29 > 0` into an ERROR,
and tightening on observation IS self-tightening, which the owner rejected on stated
grounds (a reader with a write side effect; tree dirt feeding the `id:aa93` deferral; no
concept of an AUTHORITATIVE invocation, since this checker also runs against fixtures).

**A staleness-detector variant does not rescue it either**, and it is worth recording why so
it is not re-proposed: making `current < baselined` a blocking finding would fire at
**state 1**, where Bravo has legitimately SHRUNK to 0 -- breaking assertion (0), *"improving
an item never breaks the ratchet"*. Blocking-on-stale and clean-on-shrink are mutually
exclusive. As a WARN it fires at state 2 but does not fail `--strict`, so assertion (1)
still fails. There is no configuration of the ratified design that passes both.
