### The counting rule

A line counts when it is (1) INDENTED and non-blank, (2) NOT inside a fenced block, and
(3) carries at least one `<!-- id:XXXX -->` anchor whose match does not begin inside an
inline-code span (a backticked anchor is prose quoting an address, not an address --
id:2964's mask half, imported rather than re-derived). A counted line is **addressable**
when it carries EXACTLY ONE such anchor; two or more make it **unaddressable**, because per
id:6059 both `meeting/md-merge.py` and `relay/scripts/lib-typed-edges.sh` REFUSE a
multi-marker line -- it resolves to nothing, so no tool can address it and no promote pass
can move it. Addressable lines are further split by whether they are `- [ ]`/`- [x]` shaped,
because **only a checkbox line is a sub-ITEM**; a bolded sub-heading with an anchor is
addressable but has nothing to promote.
