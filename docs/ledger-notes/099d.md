# id:099d -- `LEDGER_NOTE_POINTER_RE` is unanchored, so prose naming a note is charged as a pointer

> Hand-written 2026-09-10 during a `/relay human --all` sweep. NOT relocated by
> `tools/ledger-shrink.py`, so this note makes no "reproduced verbatim" claim.

## The defect

`relay/scripts/classify-repo.sh:198`:

    LEDGER_NOTE_POINTER_RE = re.compile(r"((?:[A-Za-z0-9_.-]+/)+[0-9a-f]{4}\.md)")

It matches any path-shaped token ending in `<4-hex>.md` **anywhere in raw ledger text**.
It is not anchored to the `-- detail:` marker, requires no link syntax, and does not care
whether the surrounding sentence is a pointer or a description. `:303` scans
`REVIEW_ME.md` as well as the two ledgers, widening the surface.

When the named file does not exist, the `id:f3d2` fail-safe charges **32,768 B**
conservatively so the prompt-size gate cannot under-count. A false match therefore costs
a real 32 KB against `id:4f9b`'s dispatch budget, on every classification, forever.

## Two confirmed instances, both found 2026-09-10, both by the same shape

1. **dotclaude-skills.** `REVIEW_ME.md:319` is a review box *about* this charge, and its
   own prose spells `docs/ledger-notes/4983.md` twice. The repo was charged 32 KB for a
   note named only in the sentence describing the charge. Note `ROADMAP.archive.md:4584`
   is INNOCENT: it points at `6546.md`, which exists.
2. **loderite.** `RELAY_LOG.md` carries the prose *"Friction: no `docs/roadmap-notes/e57b.md`
   or `3905.md` exists"*. Charged 32 KB for a file named only in a sentence asserting its
   non-existence. loderite has its own open REVIEW_ME box naming this.

## Why it matters more than 32 KB

loderite spent the day over the 300,000 tok dispatch budget and was handed back twice. Any
false 32 KB charge is spent against exactly that gate.

## The fix

Anchor the scan to the `-- detail:` pointer construct rather than matching bare
path-shaped tokens. This is the `id:2964` class one tool over: a regex that runs across
PROSE and finds structure in it. Do NOT narrow it to an enumeration of today's note
directories -- `id:d4d3` deliberately generalised the directory half, and loderite uses
`docs/roadmap-notes/` while this repo uses `docs/ledger-notes/`.

## Verification that discriminates

A fixture whose ledger contains a sentence NAMING a nonexistent note, with no
`-- detail:` pointer to it, must charge 0 B. A real `-- detail:` pointer to a missing
note must still charge the 32,768 B fail-safe -- the `id:f3d2` guard must not be weakened.
