# `docs/ledger-notes/` -- conventions

Per-item detail files under the `id:0d7c` ledger line-shrink format. One file per ledger
item, named `<id>.md`. The ledger keeps the item's title, lane tag, `id:` anchor, every gate
marker and a pointer here; the prose lives in the note.

This file exists so each note does not have to carry the explanation. It is the pointer
target named in every note's header, and it is the reason that header is one line
(`id:e567`, owner-ratified 2026-09-04: shrink the header, do not change the format).

## What a note's header claims

A note generated by `tools/ledger-shrink.py` says only where it came from, plus a pointer
here. **Read the following as part of every such header:**

> The item line keeps its title, lane tag, `id:` anchor and every gate marker. **Nothing was
> deleted** -- the prose below each `## From` heading is reproduced verbatim from the ledger.

**That claim holds BY DEFAULT and is defeated BY EXCEPTION.** A note whose prose has been
edited since relocation says so in its OWN header, and the declaration there overrides the
default above.

## Notes are EDITABLE, and an edit is DECLARED in the note's header

Owner-ratified 2026-09-02. When a fleet rule is violated inside relocated prose -- retired
vocabulary, the lane-delimiter migration, a banned token -- **fix it in the note** and say so
in the header. Notes are not immutable.

Two reasons. A note that permanently violates a rule keeps that rule's guard red forever; and
note prose gets copied back out into new items, so a violation parked here is a violation in
flight.

**Why the declaration is load-bearing rather than bookkeeping:** the default claim above says
the prose is reproduced verbatim. An edit makes that sentence FALSE for this note. The
declaration is what keeps the note honest about itself, which is why it belongs in the header
and not only in a commit message.

The alternative -- exempting notes from fleet rules -- is what we had **by accident rather
than by decision**: the vocabulary ratchet is a staged-diff hook matching a checkbox line's
leading lane bracket, and notes contain no checkbox lines, so it structurally cannot fire on
them. A retired token stayed invisible for exactly that reason.

## Section headings name the LOGICAL ledger

`## From TODO`, not `## From TODO.md`. Physical paths go stale at the archive boundary when
an item moves to `TODO.archive.md`; the logical name does not.

## Authored notes

A note written directly, rather than relocated by the tool, says so in its header instead.
The verbatim claim does not apply to it -- there is no prior ledger prose to reproduce.

## Backlinks

`docs/ledger-notes/BACKLINKS.md` maps each id to the meeting notes that cite it.
