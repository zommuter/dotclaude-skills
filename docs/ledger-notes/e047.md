### The defect

`SH_ASSIGN_RE` in `tools/ledger-continuations.py` truncates a MULTI-LINE shell assignment at
the first quote, because its right-hand-side alternation stops there. So an assignment like

```sh
outbullet=$(grep -rhF 'OUT of scope' "$ROADMAP" \
                                     "$ROOT/docs/ledger-notes")
```

is read as though the `docs/ledger-notes` operand were absent.

### Why it is the dangerous direction

The consequence in the observed case is a FALSE REFUSAL:
`tests/test_roadmap_scope_table_consistency_c480.sh:84` is a genuine consumer of `id:6b35`'s
body that is ALREADY union-anchored (the test says so at `:75-77`), and it was refused instead
of cleared. Loud, safe, wrong.

**But the same parser bug in the other direction is a MISSED UNION, and the code itself calls
that "the one place a mistake is UNSAFE"** (`tools/ledger-continuations.py:208-211`). A read
whose notes operand is truncated away looks ledger-only, and a construct that should have been
cleared as union instead... is refused. Re-read that: in this instance the truncation removes
a NOTES operand, so it pushes toward refusal. The hazard is the general one -- a rhs the
parser silently mis-reads produces a corpus verdict nobody can trust in EITHER direction, and
`id:1447` exists precisely because a wrong clear is silent.

So the fix is not "reduce a false positive". It is "make the assignment parser stop lying
about what a read touched".

### What to build

Parse a shell assignment's right-hand side across continuations rather than to the first
quote. At minimum: honour backslash-newline continuation, and do not terminate the rhs inside
a quoted string or a `$(...)` / backtick substitution.

Add a fixture whose assignment spans lines with the notes operand on the SECOND line, and
assert the construct scores `union`. That fixture must FAIL today.

- **Acceptance**: a multi-line shell assignment whose notes operand sits after a continuation
  is parsed whole, and its constructs score `union`; the `c480.sh:84` false refusal
  disappears; and no construct that was `ledger` becomes `union` without its read genuinely
  touching the notes.

- **Done-check**: `tests/test_roadmap_scope_table_consistency_c480.sh:84` no longer appears in
  the refusal for a restored `id:6b35` body, and the new multi-line fixture is `union` where
  it is `ledger` today.
