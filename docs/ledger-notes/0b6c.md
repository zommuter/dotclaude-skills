Owner authorised a time-boxed trial of `id:1048` bounded auto-integrate: *"let's test it for a few

## How it is enabled, and what is deliberately NOT done

Per-run only, at launch:

    AUTO_INTEGRATE_ORPHANS=1 /relay --afk        # or --auto-integrate-orphans

**The OFF default is NOT flipped, and must not be.** `relay/SKILL.md:933` and
`relay-loop.js:184-196` both record that default as a STANDING OWNER DECISION rather than a
preference: `a4e9-D1` ruled "NO auto-integration", `id:1048` amends it only to a hard-bounded form,
and enabling it grants the pool an autonomous merge-to-main capability, so it must be an explicit
per-run act. Authorising a trial is not authorising a default change; if the owner later wants the
default flipped, that is a separate ruling that amends `a4e9-D1` and should say so.

## What to observe -- and why "nothing happened" is NOT a pass

**The predicted outcome of this trial is ZERO integrations, and that outcome must not be read as
validation.** Two independent reasons it is near-inert, both measured:

1. `id:5b12` tick-ownership: GATE 1 wants the bound item ticked `[x]` ON THE ORPHAN, and the
   executor contract forbids executors ticking their own boxes, so a pool-produced id-bearing
   orphan normally fails it by construction.
2. All three currently parked orphans are predicted to REFUSE, and the prediction is recorded here
   in advance so the trial can be scored rather than narrated:
   * `...-21736-execute-b437-0` -> binds `b437` (open) -> GATE 1 check 1 refuses.
   * `...-12943-execute-repo-0` -> no item in branch, HEAD names `id:b437` (open) -> refuses.
   * `...-5121-execute-repo-0` -> no item in branch, HEAD names `id:6d7e`; `6d7e` is closed but
     lives in the ARCHIVES, which GATE 1 does not read, so check 2 ("not marked COMPLETE") refuses.

So a silent trial is the EXPECTED result and tells us nothing new. **A positive observation is one
of:** (a) a REFUSAL logged with a reason that matches a prediction above -- that validates the gate
path end-to-end; (b) a refusal with a reason NOT predicted above -- that is the interesting case and
should be read before acting; (c) an actual integration, which given (1) can only happen on an
UNBINDABLE complete orphan and should be inspected by hand the same day.

Scoring rule, stated so it cannot be retrofitted: **zero events = inconclusive, not success.** If a
few sessions pass with no log lines at all, the honest conclusion is that the trial did not exercise
the feature, and the next question is whether `id:5b12` makes it permanently unexercisable rather
than whether it is safe.
