**(a) `TICK-READY` manufactured -- the one that matters.** `orphan-scan.sh:229`
`wait_re='\b(observe|verify|awaiting|gated|re-evaluate|let it run)\b'` is an EXTERNAL-WAIT
suppressor matched against the ledger LINE. Relocating an item's body deletes the match, and
losing a suppressor does not hide a finding, it INVENTS one. Measured here: `wait_re` matches
on open TODO lines fell 265 -> 107, and exactly one item flipped. `id:2b4b`'s sole suppressor
was the word `VERIFY` in its prose; it now reports "TICK-READY (green: ..., no gate) -- ready
to tick", while the relocated prose it lost says *"Close or re-scope this item against the code
rather than against its own prose."* Every other consumer found so far fails toward silence.
This one fails toward telling a reviewer to close a live item.

**(b) `GATE-STALE` zeroed by blame-age.** `orphan-scan.sh:461-462` computes age from
`git blame` author-time on the ledger line, against `ORPHAN_SCAN_SHIPPED_AGE_DAYS` (default
14). A shrink REWRITES every line it touches, so every shrunk item's age resets to 0 and the
class is suppressed for a fortnight whether or not its gate lexeme survived. Measured 13 -> 1.
This is not fixable by any keep-pattern: the signal is the line's git history, and rewriting
the line destroys it by construction. Any post-shrink baseline of this scan must force
`ORPHAN_SCAN_SHIPPED_AGE_DAYS=0`, or the green is meaningless.

`id:4425` is itself one of the 16 survivors and its text describes this very scan.
