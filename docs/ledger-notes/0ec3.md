## From TODO

**The case in one line:** a single fact -- *which delimiter is canonical in a lane tag* --
is represented in at least four places that currently disagree, with no mechanism that
propagates a change from any one of them to the others. The result is a migration that
cannot be finished, cannot be verified by the test suite, and cannot be safely completed by
the obvious action.

### The four representations, measured 2026-09-09

| Where | Says |
|---|---|
| `relay/references/hard-lanes.md` (the declared SSOT) | old vocab is current: "The three lanes" `[HARD - pool]` / `[HARD - meeting]` / `[HARD - hands]` |
| `hooks/pre-commit-lane-vocab.sh` (the enforcer) | old vocab is RETIRED -- it BLOCKS a commit adding `[HARD - pool]`, naming `[HARD]` as the replacement |
| `relay/scripts/classify-repo.sh` + 5 sibling readers | BOTH spellings are valid (`LANE_TAGS` lists each tag twice, id:e8d4; `gather-human-backlog.sh:481` uses a `[—-]` character class) |
| `project_manager/src/project_manager/scan.py` | em dash ONLY -- `_GATE_MARKERS` contains the literal `"[HARD — decision gate]"` with no ASCII variant |

`hard-lanes.md` itself names `scan.py` as one of the two consumers that MUST agree with it.
They do not, and neither matches the enforcer.

### Why this is an information-flow case and not merely a bug

1. **The token is simultaneously prose punctuation and load-bearing syntax.** The same
   character is an em dash in a sentence and a field separator in `[INPUT — decision]`.
   Measured in fleet ledgers (`ROADMAP`/`TODO`/`REVIEW_ME`): **656 LIVE lane tags** carrying
   the old delimiter, against **11,979 raw em dashes** in the same files -- an 18x ratio. A
   blanket rewrite is therefore ~18x wider than the migration, and would corrupt prose that
   legitimately QUOTES the old spelling, including the documentation explaining the migration.
2. **Dual-tolerant readers make a half-applied migration indistinguishable from a finished
   one.** Because most readers accept both, nothing fails while the corpus is half-converted.
   `relay/scripts/lane-delimiter-scan.sh` (`id:70bc`) had to be built for exactly this reason;
   its header states the problem outright -- without it "the suite is green" does not mean the
   migration finished, and dropping the dual tolerance has no checkable closing condition.
   That is a purpose-built instrument compensating for the absence of a propagation mechanism.
3. **Tool names imply a coverage they do not have.** `lane-convert.sh` (`id:4f02`) reads as
   the converter for this, and is not: it is a VOCABULARY converter
   (`[HARD — pool]` → `[HARD]`) whose own output still emits `[INPUT — meeting]` with an em
   dash, and it passes `[INTENSIVE — <res>]` through untouched. There is NO delimiter
   converter anywhere; `lane-delimiter-scan.sh` is detect-only. This session recommended
   `lane-convert.sh` for the job and had to retract it after reading the source -- the failure
   was believing a name instead of reading the tool.
4. **The safe-looking action is the unsafe one.** The obvious move -- swap the delimiter
   everywhere -- silently removes gated items from `scan.py`'s counter, because that reader
   matches an em-dash literal. This is the `id:d35a` silent-no-op class: no error, no failing
   test, a dashboard that quietly under-reports. The global `CLAUDE.md` already carries the
   rule ("never hand-swap a delimiter in isolation"); this is its first MEASURED instance.

### What the case argues for

Not "finish the migration" -- that is `id:70bc`'s job. The information-flow claim is narrower
and more general: **when one fact is replicated across a spec, an enforcer, several readers and
a cross-repo consumer, the replication itself is the defect.** The fleet's mitigations here are
all downstream compensations -- dual-tolerant readers, a bespoke completion detector, a
pre-commit ratchet, a prose rule in `CLAUDE.md` telling humans and agents to "match both
spellings when reading, emit the new one when writing". Four mechanisms, none of which
propagates the fact; each one exists because the fact has no single authority that the others
derive from.
