## 7. Gotchas learned — worth not rediscovering

- **A comment about what the SHELL does is not a claim about what the PROXY accepts.** The line
  above `mechArg` said backticks are "inert inside single quotes and preserved VERBATIM". True of
  bash. False of the proxy. That one sentence cost three integrates. A test now guards the wording.
- **Re-running someone else's suite only tests what their fixture covers.** I re-ran git-annex's
  21/21 green myself and signed off; the pool then found a real C-quoted non-ASCII relpath defect
  the fixture had no case for. Green ≠ correct.
- **A delegated agent contradicting your brief is the point.** All four did: the `758a` agent
  refused my "derive from the repo's own HEAD" instruction for `verify-isolation.sh` (its arg is a
  linked worktree — deriving from its own HEAD would equal itself and silently defeat the gate);
  the `7354` agent refuted the item's own hypothesis; the `2e7a` agent built a fix, found it broke
  a ratified test, and reverted rather than ship it.
- **relay-loop.js (~4,600 lines) kills agents.** One died on "Prompt is too long". Brief agents to
  `grep -n` then `sed -n 'START,ENDp'` — never `Read` it whole.
- **`tests/test_pipefail_sigpipe_lint.sh` (id:81d5) will fail your test** for `| grep -q`,
  `| head -N`, `| sed -n 'Np'`. Use a variable + `[[ ]]`, or `awk 'NR==1'` (no `exit`).
- **`make relay-proxy-start` does not exist** — the SKILL.md prose names it, but the proxy is a
  systemd user service: `systemctl --user restart mechanical-proxy.service`.
- **A commit message full of backticks breaks zsh quoting.** Use `git commit -F <file>`.
- **`git-lock-push.sh` without `--remote origin` pushes to EVERY remote.** I did that on
  git-annex; nothing published only because its public `upstream` is read-only `git://`. That is
  luck, not safety — and it is what the in-flight §6 change exists to fix.
