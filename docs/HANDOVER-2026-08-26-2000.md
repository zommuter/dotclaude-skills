## 7. Gotchas learned — worth not rediscovering

- **A comment about what the SHELL does is not a claim about what the PROXY accepts.** The line
  above `mechArg` said backticks are "preserved VERBATIM" — true of bash, false of the proxy, and
  it cost three integrate hops. A test now guards the wording.
- **Any executor summary containing a markdown backtick used to 404 its own integrate.** Fixed at
  `mechArg`; durable stdin-channel migration is `id:76fd`. **Never loosen `_command_allowed()`** —
  tried, reverted, breaks the ratified `id:a05c` test.
- **Re-running someone else's suite only tests what their fixture covers.** I re-ran git-annex
  21/21 green and signed off; the pool then found a real C-quoted non-ASCII defect the fixture had
  no case for.
- **Delegated agents contradicting your brief is the point.** The `758a` agent refused my
  "derive from the repo's own HEAD" instruction for `verify-isolation.sh` (its arg is a LINKED
  worktree — deriving from its own HEAD equals itself and silently defeats the gate); the `7354`
  agent refuted the item's own hypothesis; the `2e7a` agent built a fix, found it broke a ratified
  test, and reverted rather than ship it.
- **Verify a modified pre-existing test by RESURRECTING the old one** against the new tree. That is
  how the `test_relay_driver_ticks.sh` change was confirmed stronger (5 passed / 2 failed, both
  failures purely the hardcoded `v12` literals).
- **relay-loop.js (~4,600 lines) kills agents.** Brief them to `grep -n` then `sed -n`, never Read.
- **`tests/test_pipefail_sigpipe_lint.sh` (id:81d5)** fails the suite on `| grep -q`, `| head -N`,
  `| sed -n 'Np'`. Use a variable + `[[ ]]` or `awk 'NR==1'` (no `exit`).
- **`make relay-proxy-start` does NOT exist** — it is `systemctl --user restart mechanical-proxy.service`.
- **A commit message full of backticks breaks zsh quoting** — use `git commit -F <file>`.
- **`git-lock-push.sh` now defaults to `origin`** (`id:a73b`); `--all` opts into every remote. The
  one call site that relied on the old all-remotes default (`integrate.sh`'s non-substantive
  branch) was updated to pass `--all` explicitly.
