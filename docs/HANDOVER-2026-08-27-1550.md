## 5. Gotchas learned today

- **The proxy claim was narrowed.** `mechanical-proxy.py` does not rewrite model or context **on
  the wire** — that is ALL that was measured. Setting `ANTHROPIC_BASE_URL` demonstrably changes
  Claude Code's own behaviour anyway (it disables `/remote-control`). "Exonerated" was too strong.
- **Children do NOT inherit the parent's model or window.** All 23 `agent()` sites specify a
  model. 84,294 Sonnet children exist inside Opus-parent pools, and they failed at ~176k — the
  window tracks the CHILD's model. Residual: no pool has ever knowingly run from a Sonnet parent.
- **zsh does not word-split unquoted `$var`.** `set -- $r` in a for-loop silently produced
  all-zero arithmetic; a 56-repo remote census returned 0. Caught only because every row printed
  an identical constant. Use `bash -c` or python for anything with word-splitting.
- **A green suite is not a negative control.** One agent's stated control for a gate change was
  "the driver won't even import" — an unreached fixture. Verified functionally against the module
  instead.
- **`grep -c` on a public repo's ledgers false-matches.** "COUNT CORRECTION" hit an unrelated item;
  always `grep -n` and look.
